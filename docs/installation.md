# Access and installation

Open [ZYN.STORE](https://store.zynoks.com) in a browser. Operators use [ZynBoard](https://eboard.zynoks.com) with an account provided by the owner. No public registration for dashboard operators is established.

No verified native installers or downloadable releases were found. Do not use source archives from this product repository as an installer. No mobile store listing or installable PWA workflow is verified.

The websites require an internet connection. Desktop Chromium rendering has been checked. Other browsers, mobile devices and operating systems have not received a complete compatibility test.

Reload after a website update. If a tab still shows an older interface, close it and reopen the website before clearing site data. Site data can contain your cart, favorites and dashboard preferences.

There is no application package to uninstall. Sign out, close tabs and optionally clear site data for each website in your browser. Clearing site data does not remove server-side records. Request account or data assistance at contact@zynoks.com.
