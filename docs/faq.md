# Frequently asked questions

**Are ZYN.STORE and ZynBoard the same product?**

They are linked parts of one product: the shopping website and its operator dashboard. This public repository documents both. Their application code stays in separate private repositories.

**Can I download or self-host it from this repository?**

No. It contains product materials, not application source or a verified installer. Use the hosted websites listed in the README.

**Is there a mobile app?**

Mobile layouts exist in the web implementation. No native Android or iOS release, app-store listing or verified installable PWA is offered here.

**Are the screenshots real?**

Yes. They show the rendered website interfaces in an isolated browser, with intercepted API responses, sample products and neutral image placeholders. No customer records were used. The abstract cover is generated artwork, not a screenshot.

**Can I pay by card?**

Card processing was not verified. The current checkout implements cash on delivery and bank transfer when configured. Follow the choices and instructions currently shown by the store.

**Do dashboard settings control the live store?**

Some settings only persist in the current browser. Local coupon entries, notification toggles and team lists do not establish live discounts, sent emails or authorized operator accounts.

**Can I use the dashboard totals for accounting?**

They summarize recorded orders and can include unpaid or canceled orders. Inventory counts and traffic conversion figures also have limitations. Reconcile with authoritative records.

**Does a support-ticket success message mean a ticket was delivered?**

The dashboard ticket flow is simulated. The storefront contact flow does not establish email delivery either. Use contact@zynoks.com for support.

**How do I remove an account or request help with my data?**

Contact contact@zynoks.com privately. Clearing browser data does not delete server-side records.

**Is the private source now open source?**

No. The public repository grants no license to the private application. See [rights and credits](../RIGHTS.md).
