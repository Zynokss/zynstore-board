# Troubleshooting

| Symptom | What to try |
| --- | --- |
| Catalog is empty | Clear search and filters, reload and check your connection. An unavailable service can also appear empty. |
| Dashboard returns to login | Sign in again with your authorized account. If access still fails, contact the operator privately. |
| Dashboard shows zero totals | Reload and check for connection or session problems. Zero values alone do not prove there are no records. |
| Bank transfer is unavailable | Choose another offered method or ask the operator. Do not send funds to account details from an old screenshot. |
| Manual order disappears | The manual-order UI currently keeps entries in memory. Do not treat its confirmation as server persistence. |
| Settings do not change checkout | Several dashboard settings are browser-local and do not control the live store. Ask the operator to confirm the live rules. |
| Restored product has a new identity | Trash restoration recreates a product rather than restoring its complete original record. |
| Support form reports success without a reply | Use contact@zynoks.com; form confirmation does not establish message or email delivery. |
| Interface looks outdated | Close and reopen the tab, then reload. Read the backup guide before clearing site data. |

For a public bug report, include browser/version, operating system, the affected screen and safe reproduction steps. Redact names, email addresses, order IDs, payment details and account data from images. Do not upload cookies, console dumps or network logs without checking them for sensitive information.

For sensitive reports, contact contact@zynoks.com privately. No response-time commitment or mailbox delivery test is claimed.
