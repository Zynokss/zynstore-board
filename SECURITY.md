# Sensitive reports

Send security concerns or reports containing sensitive information privately to **contact@zynoks.com**. Do not open a public issue containing passwords, session cookies, tokens, private notes, customer records, payment receipts, order references or unredacted screenshots.

Describe the affected website and the issue with the minimum information needed. Do not include working credentials or private data in an initial report. This repository does not establish a response-time guarantee or a security bounty. Mailbox delivery has not been tested as part of this preparation.
